# TSRClust Reproducibility Bundle

This directory contains the analysis code used to reproduce the TSRClust
manuscript results. It is intended for the public GitHub repository and is
excluded from the R package tarball by `.Rbuildignore`.

## Requirements

The analyses were run in R. The main required packages are `tclust`, `dbscan`,
`mclust`, `mlbench`, `ggplot2`, `otrimle`, `teigen`, and `pdfCluster`.
The package source itself imports only the packages listed in `DESCRIPTION`.

## Directory Structure

- `config_v2.R`: main manuscript analysis settings.
- `config/config.R`: shared low-level configuration.
- `core/`: data-generation, TSRClust core, and utility functions.
- `competitors/`: robust, density-based, and model-based competitor wrappers.
- `simulation/`: final simulation worker script.
- `real_data/`: olive-oil and Shuttle real-data workflow.
- `summaries/`: summary, diagnostic, and manuscript asset-generation scripts.
- `evaluation/`: external clustering performance metrics.
- `hpc/`: optional SLURM setup script.

## Final Settings

The manuscript simulations used `nstart = 500`, `null_reps = 49`,
`structure_alpha = 0.05`, `min_density_ratio = 2`, `novelty_prob = 0.995`,
`eps_quantile = 0.90`, and `eps_grid_size = 31`.

Stage-I simulation settings used `K = 2`, `alpha = 0.10`, and `c = 20` except
where a simulation manifest deliberately varied a design factor.

Real-data settings were:

- Italian Olive Oil: `K = 3`, `alpha = 0.10`, `c = 100`.
- Statlog Shuttle: `K = 2`, `alpha = 0.05`, `c = 20`.

## Results Boundary

Replication-level CSV exports and manuscript summaries are stored in the
repository-level `results/` directory:

- `results/raw_results/`
- `results/summary_results/`
- `results/real_data_results/`
- `results/simulation_design/`

Task-level temporary HPC files are intentionally not archived because the
replication-level CSV files are the reproducibility boundary for manuscript
numerical claims.

## Re-running Analyses

Use `simulation/10_final_sim_worker_v2.R` with the manifests in
`results/simulation_design/` to regenerate replication-level simulation output.
Use `summaries/20_final_summary_v2.R` and
`summaries/21_final_diagnostics_v2.R` to regenerate summaries and diagnostics.
Use `real_data/02_realdata_v2.R` to reproduce the olive-oil and Shuttle
analyses. Manuscript tables and figures are generated by
`summaries/generate_assets.R`.
